Overview

A mobile robot dropped into an unknown space has to answer four questions: Where can I go? Where am I? How do I get there? How do I stay on the path? This project answers each one on a TurtleBot3 in Gazebo.

The stack

Frontier exploration→SLAM Toolbox (map)→AMCL (localize)→A* (plan)→Pure pursuit (track)

What I did

Explored and mapped

Combined SLAM Toolbox with frontier exploration so the robot drives toward the edges of the known map until the environment is covered.

Localized

Used AMCL to localize the TurtleBot3 on the finished map.

Planned with A*

Implemented A* path planning with replanning when the path is blocked.

Tracked with pure pursuit

Implemented a pure-pursuit controller that steers toward a lookahead point on the path.

Also: UR3e joint trajectories

In a robotics lab (ECE 569), I generated joint-angle trajectories for a Universal Robots UR3e and played them back on the arm's model in RViz through a ROS 2 joint publisher, checking the tool path against the intended trajectory before submitting it.

What I learned

Each layer depends on the one below it. A good planner can't help a robot that is badly localized, and the lookahead distance in pure pursuit is a real trade-off: too short and the robot oscillates, too long and it cuts corners.
