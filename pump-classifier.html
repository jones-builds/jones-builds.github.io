Overview

A failing pump often sounds different before it stops working. This lab built a full condition-monitoring loop: stream a pump's sound over MTConnect, classify its state with a CNN, and show the result live.

Pipeline

Microphone→MTConnect adapter→Agent / collector→Mel-spectrogram→CNN→Grafana

The three states

  • OFF: pump idle
  • ON – air leaking: running with a leak in the line
  • ON – vacuum: running and holding vacuum normally

What I did

Streamed audio over MTConnect

Configured the adapter and collector scripts to publish the sound stream as MTConnect data.

Built the features

Converted audio chunks into mel-spectrograms, setting the sample rate, chunk size, FFT size and mel-band count to the lab's specification.

Classified with a CNN

Ran a convolutional neural network that labels each spectrogram as one of the three pump states.

Visualized it live

Displayed the predicted state on a Grafana dashboard running on the Raspberry Pi.

Debugged the plumbing

Fixed FlatBuffers compatibility issues and problems in the MTConnect adapter and collector scripts so data flowed end to end.

What I learned

The model was the easy part. Most of the work in an IIoT system is getting data reliably from the sensor to the model to the dashboard, and handling the version mismatches between the pieces along the way.
